Demo fence · not one mega-prompt

How the best teams research, then write

Two belts. Research never writes the ad. The writer never invents the news. Grok can fetch headlines. It does not get to score them, and it does not get to hide a brief inside a caption.

1. Research

Industry: gpt-researcher diamond

Listen

Locked queries. Google News stays. Grok web search is a fourth pipe: India skincare / Neutrogena today. Real article URLs only.

↓
Score

Drop unsafe. Brand-fit on a shortlist. 8+ = closer look. Fetcher never scores.

↓
Plan 3 angles

Content ideas, not captions. “Night routine after double cleanse” is an angle.

↓
Read the real page

Publisher URL. Page is DATA. No window.WIZ_global_data.

↓
Skeptic

A different pass kills unsourced lines. Then file what / why now / who.

Now: Google tracker + “Deep-dive after scorer gate” + JS dump.

After: Vogue India headline, a human why-now, a link that opens the story.

2. Post prompts

Industry: examples, then many, then filter

Brief (code)

Idea + 3 posts we would ship + approved phrases + banned list. No “sound warm.”

↓
Writer prompt

Match those 3 examples. Tie to today’s sourced idea. Write 8 captions a person could paste. JSON only.

↓
Code filter

Drop stage notes, smashed English, banned words. Keep 2–3.

↓
Judge + you

Claims check. Then Your call. Nothing goes live.

Now: “Humidity ho, barrier calm rahe. Soft close: add to routine.”

After: “Double cleanse tonight. Hydro Boost after — dermatologist tested.”

Where Grok sits

Grok is a tool inside steps. It is not the belt.

Fetcher: optional web search, locked query, URLs only.
Scorer: brand-fit on a shortlist.
Researcher: angles + read, pages as data.
Copywriter: 8 lines from examples, then code keeps 2–3.

Not this: one prompt that “finds a trend and writes the post.” That is how claims leak into research.
