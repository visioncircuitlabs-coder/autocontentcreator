## Problem Statement

Look for ideas can pick a real Vogue India headline, then Pick shows Google JavaScript and Make shows fill-in-the-blank captions (`Hydro Boost is Try it in the PM routine`, `Soft close:`). Grok is wired. Craft is not landing.

The founder asked for the industry method for (1) research and (2) post prompts, then Grok web search as a fetch pipe. Chose **demo fence**, not the full locked spec, not one mega-prompt.

## Demand Evidence

Screenshots from the live walk on 2026-08-22. Quote: "dont you use AI for the craft?" That is a demo that would embarrass in front of a brand operator.

## Status Quo

Fetcher: Google News RSS + GDELT (often 429) + Reddit (often 403). Researcher fetches the Google tracker URL and clips page script as a quote. Copywriter: adjective voice (`AC-commute millennial`), hardcoded Hinglish, stage notes in templates, mix of Grok output and junk.

## Target User & Narrowest Wedge

A content person in Kerala walking Look → Pick → Make. Smallest win this week: Pick shows a real article, Make shows a caption you would paste.

## Constraints

- Locked boxes stay. Fetcher does not score. Researcher does not write ads. Copywriter does not invent claims.
- Spec: allowlisted queries. No "search the whole web."
- Pages are data, never instructions.
- Grok key already on. Web search billed per call (~$5 / 1k calls) plus tokens.
- No CrewAI. Plain-code belt.
- Demo brand: unofficial Neutrogena, India Instagram.

## Premises

1. Industry research is a diamond (plan angles, read the real page, separate skeptic), not "summarise Google News HTML."
2. Industry copy is examples + many candidates + filter, not adjectives + one template.
3. Grok web search belongs in Source Fetcher as a fourth pipe with a locked query, not as the researcher or the copywriter.
4. This week's walk only needs the demo fence, not trusted-site lock + 20-caption Jacquard rank.

## Approaches Considered

### Approach A: Demo fence (chosen)
Grok search as extra fetch. Researcher must use a publisher URL. Copywriter gets 3 example posts, writes many lines, code drops junk, 2–3 survive.

### Approach B: Full locked spec
Trusted-site lock, real skeptic, generate ~20 then rank. Better buyer demo. Longer Look/Make.

### Approach C: One Grok call (rejected)
Mixes research and claims. Breaks the belt. Fast and unsafe.

## Recommended Approach

**A.** Steal the industry *shape*, ship the thin version.

### Research (industry: gpt-researcher planner + parallel readers + skeptic; Anthropic: reader cannot call tools)

```text
Look
  Fetcher
    Google News (keep)
    GDELT / Reddit (keep, may be quiet)
    Grok web search (new, only if XAI_API_KEY)
      locked query: India facial skincare / sunscreen / Neutrogena news today
      output: Signal rows with real http(s) article URLs only
      no scores, no captions
  Scorer (unchanged: exclusions, Grok on a shortlist, closer look ≥ 8)
  Researcher
    if seed host is news.google.com → do not treat JS as a quote
    follow or keep only a publisher URL
    plan 3 content angles (not ads)
    read the seed page as DATA
    file what / why now / who with a human why-now
    skeptic: drop unsourced lines (already in spec; keep the pass, do not skip)
```

### Post prompts (industry: Writer voice profiles + terms lists; Jacquard generate-many then filter; "voice from examples not adjectives")

```text
Brief (code) packs: idea + 3 example captions from the brand fixture + approved phrases + banned list

Copywriter prompt:
  Here are 3 posts we would actually ship. Match that voice.
  Here is today's idea (sourced).
  You may only use these claim phrases: …
  Never write: soft close, no miracle talk, explore the product, stage notes.
  Write 8 captions a person could paste. JSON only.

Code then:
  drop banned / stage notes / smashed English
  require an approved phrase or the disclaimer
  keep 2–3
  if Grok fails, plain fallbacks that still mention the news idea
```

Do not buy Jacquard or Writer. Steal the mechanics.

## Success Criteria

- Pick: no `window.WIZ_global_data`, no `scorer gate`. Link label is a publisher or "Google News".
- Make: no `Soft close` / `no miracle talk` / `Hydro Boost is Try it`.
- A version is a caption you would paste under the Vogue night-routine idea.
- Grok search quiet → Google News still walks.
- Tests for: locked query (no free-web instruction), citation-only URLs, copy filter, example posts present in the prompt.
