# Command Center — the walk

One idea: a brand person makes a post from today's news, says yes or no with a reason, and downloads a pack that does not go live.

## Owns / must not own

| Owns | Must not own |
|---|---|
| The five-step walk and the words on it | Claims policy (Hard Rules + Product Facts) |
| Showing progress while the belt runs | Publishing to Instagram |
| Optional "Show the machine" graph | Inventing a second way to approve |
| Calling **Make the picture** after a version pick | Generating photos during Look or Make a post |

The browser does not enforce claims. The API does.

## Main flow

```text
Look for ideas → Pick one → Make a post → pick a version → Make the picture → Your call → Phone preview
```

Sample idea (practice) appears only after this search found nothing worth a closer look. It is labeled. It is not this search. Headlines from this Look stay on the page.

Junk source URLs stay off the main card. Optional **Sources** fold.

Agent map: `docs/agents/ui.md`.

## Failures

- A news source is quiet: say which one, keep going.
- Nothing worth a closer look: offer the sample idea.
- Blank name or why: the Yes/No buttons stay off. The API still rejects blanks.
- Picture missing: say so. The pack may still download.
